# Ubuntu Touch Launcher

Домашний экран (лаунчер) для Android в духе **Ubuntu Touch / Unity 8**: док-панель, которая
выезжает от левого края, тёмные поверхности Suru, оранжевый акцент Ubuntu `#E95420`,
круглые плиты под иконками и нижний «dash» со скоупами.

Написан на **Kotlin + Jetpack Compose**, без сторонних библиотек (только AndroidX).

```
Kotlin 2.0.21 · AGP 8.7.2 · Gradle 8.9 · minSdk 26 · targetSdk 35 · версия 1.4
```

## Что умеет

- **Домашний экран — это скоупы с точками страниц**, как в Unity 8:
  «Сегодня» и «Приложения», переключаются свайпом вбок.
- **Скоуп «Сегодня»**: приветствие, часы и дата, погода (Open-Meteo, без ключа API —
  город выбирается в настройках, прогноз кешируется на 30 минут) и уровень батареи.
- **Размытые обои**: устройство-обои уменьшаются, размываются box-блюром, а их
  доминирующий цвет подмешивается в акцентное свечение фона.
- **Coach mark при первом запуске** — подсказка про свайп от левого края.
- **Работает как настоящий HOME-лаунчер** — при установке система предложит выбрать его
  лаунчером по умолчанию.
- **Свайп от левого края** открывает док-панель; домашний экран при этом слегка
  отъезжает и масштабируется (параллакс, как в Unity 8). Закрытие — тап по затемнению,
  системная «Назад» или кнопка-шеврон.
- **Универсальный поиск**: приложения, контакты (с разрешением — звонок прямо из
  результата), системные настройки (`wifi`, «батарея»…), калькулятор в строке
  (`2+2*7`, `15%`) и веб-поиск. Понимает латиницу и кириллицу: «telegram» находит «Телеграм».
- **Шорткаты приложений** в листе долгого нажатия (`LauncherApps`), когда лаунчер выбран
  домашним.
- **Скрытые приложения**: прячутся из сетки, «Недавних» и поиска, включаются списком в
  настройках.
- **«Сделать домашним»** — сразу открывает системный выбор домашнего приложения.
- **Закреплённые приложения** на домашнем экране (до 8 плиток) — долгое нажатие на иконку
  → «Закрепить». Пока ничего не закреплено, показывается блок «Ваши приложения».
- **Алфавитная сетка** всех приложений с заголовками-секциями, системные приложения можно
  скрыть в настройках.
- **Скоуп «Недавние»** — последние 12 запущенных из лаунчера приложений, с закреплением
  одним тапом по звёздочке.
- **Скоуп «Виджеты»** (бета, по умолчанию выключен): отдельная вкладка в док-панели,
  куда можно положить виджеты приложений. Любой виджет из списка в режиме правки
  закрепляется на главном экране (иконка «дом») и снимается оттуда тем же тапом;
  на главном он занимает свободное место ниже карточек «Погода»/«Батарея». Высота регулируется (1–3 ряда), ломающиеся
  виджеты показывают заглушку, привязка и настройка идут через системные диалоги.
  Домашний экран и пейджер не меняются — виджеты физически не попадают в свайп-скоупы.
- **Скоуп «Настройки»**: обои за лаунчером, подписи иконок, системные приложения,
  перезагрузка списка, очистка недавних.
- Обновление списка при установке/удалении приложений (broadcast-приёмник), иконки
  рендерятся в фоне, поэтому прокрутка не подтормаживает.
- Локализация: английский и русский. Тёмная тема всегда (как в оболочке Ubuntu Touch).

## Готовый APK

**[Скачать app-debug.apk](https://github.com/vetos26/Launcher/releases/latest/download/app-debug.apk)** — собран
GitHub Actions (workflow «Android build») и лежит в [последнем релизе](https://github.com/vetos26/Launcher/releases/latest).
Версия 1.4: виджеты приложений (бета) — отдельный скоуп «Виджеты» и закрепление
виджета на главном экране под карточками «Погода»/«Батарея»; плюс всё из 1.2/1.3 —
универсальный поиск (контакты, настройки, калькулятор, веб), шорткаты приложений,
скрытые приложения, кнопка «Сделать домашним».

Установка: скачайте файл на телефон, разрешите установку из этого источника и откройте APK.
Затем выберите лаунчер домашним экраном:
*Настройки → Приложения → Приложения по умолчанию → Домашнее приложение*.
На Android 10+ альтернатива: `adb install -r app-debug.apk`.

## Сборка

Нужен Android Studio (Koala или новее) либо JDK 17 + Android SDK 35.

```bash
# из корня проекта
./gradlew assembleDebug
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

Или просто откройте каталог в Android Studio и нажмите Run.

После первого запуска: **Настройки → Приложения → Приложения по умолчанию → Домашнее
приложение → Ubuntu Touch Launcher** (на разных прошивках путь немного отличается).
Кнопка «Home» начнёт возвращать на этот экран.

## Структура

```
app/src/main/java/dev/utouch/launcher/
├── MainActivity.kt            # HOME-активити, edge-to-edge, одна Compose-сцена
├── LauncherViewModel.kt       # состояние (apps, pinned, recents, настройки, обои)
├── data/
│   ├── AppEntry.kt            # модель запускаемой активити
│   ├── PackageRepository.kt   # чтение PackageManager, рендер иконок
│   ├── LauncherPrefs.kt       # SharedPreferences: закреплённые, недавние, флаги, погода
│   ├── Weather.kt             # Open-Meteo: геокодинг города и текущая погода
│   ├── Calculator.kt          # разбор выражений для строки поиска
│   ├── Search.kt              # настройки системы, транслитерация, матчинг запросов
│   ├── ContactsRepository.kt  # контакты для поиска (READ_CONTACTS)
│   ├── Shortcuts.kt           # шорткаты приложений через LauncherApps
│   ├── Widgets.kt             # AppWidgetHost: привязка, вьюхи, размеры, ошибки
│   └── ImageTools.kt          # Drawable → Bitmap, доминирующий цвет, обои
└── ui/
    ├── LauncherScreen.kt      # оркестратор: свайп, скрим, шит, drawer
    ├── HomePane.kt            # часы, приветствие, плитки, подсказка
    ├── DrawerPane.kt          # док-панель: поиск, сетка, недавние, dash
    ├── AppIcon.kt             # плитка приложения и иконка в «сквиркле»
    ├── AppDetailsSheet.kt     # лист по долгому нажатию
    ├── WidgetsScope.kt        # скоуп виджетов, пикер, режим правки
    ├── SettingsPane.kt        # скоуп настроек
    └── theme/                 # палитра Ubuntu, типографика, формы
```

Ключевые состояния: `DrawerTab { APPS, RECENTS, WIDGETS, SETTINGS }`, `LauncherUiState`
(единый `StateFlow`), прогресс док-панели — `Animatable<Float>` в `LauncherScreen`
(0 — закрыта, 1 — открыта), поэтому и свайп, и анимация работают от одной величины.
Закреплённые на главном виджеты — `state.homeWidgetIds` (подмножество `state.widgets`),
каждый рендерится в своём слоте `WidgetHostHolder.SLOT_HOME`, чтобы один и тот же виджет
мог одновременно быть открыт и в скоупе, и на главном без конфликта «одна вьюха — два родителя».

## Заметки

- APK собирается в CI (`.github/workflows/android.yml`): каждый пуш в `main`/`arena/**`
  запускает `./gradlew assembleDebug`, а сборка из `workflow_dispatch` дополнительно
  публикует релиз с APK.
- `QUERY_ALL_PACKAGES` нужен, чтобы видеть все приложения; для Google Play это
  чувствительное разрешение (для личного лаунчера и F-Droid всё в порядке).
- Обои читаются через `WallpaperManager` «best effort»: если прошивка не даёт доступ,
  лаунчер показывает собственный градиент.
- Виджеты сделаны так, чтобы ничего не ломать: `AppWidgetHost` живёт в активити с
  постоянным `HOST_ID`, слушает в `ON_START`/`ON_STOP`, виджеты лежат в отдельном скоупе
  (не в `HorizontalPager`), высота фиксирована в dp, все вызовы платформы обёрнуты в
  `runCatching`, а `getAppWidgetInfo == null` означает «виджет умер» (в скоупе — карточка-
  заглушка, на главном — виджет просто не показывается). Если лаунчер не
  домашний, привязка идёт через системный диалог `ACTION_APPWIDGET_BIND`; отмена
  настройки удаляет выделенный id, чтобы не копить мусор.
- Иконка приложения — упрощённый «круг друзей» Ubuntu, нарисованный векторно
  (`res/drawable/ic_launcher_foreground.xml`).

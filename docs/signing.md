# Постоянная подпись APK

Начиная с версии **1.5.1** APK собирается задачей `assembleRelease` и подписывается постоянным
ключом. Это значит: обновления ставятся поверх (`adb install -r` или тап по APK) без
`adb uninstall`, потому что подпись больше не меняется от сборки к сборке.

## Где лежит ключ

| Файл | Что это |
|---|---|
| `signing/utouch-launcher.p12` | PKCS12-хранилище: приватный ключ + самоподписанный сертификат, alias `utouch` |
| `signing/password.txt` | пароль хранилища (и он же пароль ключа) |

**Решение осознанное:** репозиторий публичный, ключ лежит в нём открыто. Плюсы — сборка
работает без настройки секретов и у любого, кто клонирует проект. Минусы — любой человек
может подписать этим ключом свой APK, и телефон примет его как обновление, если пользователь
сам установит файл. Для личного лаунчера это приемлемый компромисс; для публикации в
Google Play так делать нельзя — там нужен приватный ключ.

Если понадобится закрыть ключ: удалить файлы из репозитория, сгенерировать новый ключ и
положить его в секреты `SIGNING_KEYSTORE` (base64) + `SIGNING_STORE_PASSWORD`. Gradle уже
умеет читать их: переменные окружения имеют приоритет над файлами из `signing/`.

## Как устроено в Gradle

`app/build.gradle.kts` ищет ключ в таком порядке:

1. `SIGNING_KEYSTORE_PATH` + `SIGNING_STORE_PASSWORD` (их выставляет CI из секретов, если они есть);
2. `signing/utouch-launcher.p12` + `signing/password.txt` из репозитория.

Если ключа нет вообще, release-сборка остаётся неподписанной, а workflow публикует debug APK —
форки и пул-реквесты ничего не ломают.

CI после сборки проверяет подпись через `apksigner verify --print-certs` и пишет тип APK в
сводку сборки и в описание релиза.

## Сертификат

- Subject: `CN = Ubuntu Touch Launcher, O = vetos26, C = DE`
- Тип: RSA 2048, PKCS12, alias `utouch`
- Годен до: 16.11.2056
- SHA-256: `A1:9C:79:52:0B:CA:BB:8F:21:60:F9:BD:87:05:B4:65:86:66:5A:80:6F:38:29:BC:D6:82:F1:3B:3D:FC:95:EC`

## Что важно помнить

- **Один раз** после перехода с debug-подписи приложение придётся переустановить
  (`adb uninstall dev.utouch.launcher`): подпись меняется. Дальше — только обновления поверх.
- Ключ уже в git-истории. Если он попадёт в чужие руки, отозвать его нельзя — можно только
  выпустить новую версию с новым ключом (и тогда снова понадобится переустановка).
- Резервная копия ключа = сам файл `signing/utouch-launcher.p12` плюс пароль из `password.txt`.
